## 说明

- 这套类别取自 **IPTC Media Topics**（国际通用的新闻题材分类标准）：17 个顶级类目 + 3 个「艺术、文化、娱乐和媒体」子类，共 1200+ 术语、5 层结构，有官方中文词表
- 上表是**顶级类目**，够台账用；要更细粒度可去官方词表挑下级术语（如"选举""气候变化""运动员转会"）
- 「人性」（Human Interest）在 IPTC 里是独立顶级类目，别并进其他类别
- 只用这份表，**不要自创类别**——否则跨批次、跨人统计会打架
