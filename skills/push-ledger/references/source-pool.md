# 内容来源池示例（按需替换）

下面是**示例**来源池，用于筛选候选内容与回溯一手来源；按自己的领域替换即可（政策监测就换成官网/公报/权威解读，竞品监测就换成官网/财报/招聘页）。

- 中文时政/央媒：新华社/新华网、人民日报/人民网、央视新闻、光明日报、经济日报、中国日报、参考消息
- 中文市场化：澎湃新闻、新京报、南方周末、中国新闻周刊、界面新闻
- 中文财经/科技：第一财经、华尔街见闻、财联社电报、金十数据、雪球、东方财富、36氪、虎嗅、钛媒体、机器之心、量子位、晚点 LatePost
- 中文热榜信号源：微博热搜、知乎热榜、抖音热搜、小红书热搜、B站、今日头条
- 国际通讯社：Reuters、AP、AFP、Bloomberg
- 国际媒体：BBC、NYT、WSJ、FT、The Guardian、The Economist、Al Jazeera、Nikkei、SCMP、联合早报、德国之声、France 24

## 用这些来源时的两条纪律

1. **优先一手**：给原始报道机构的 URL，不要贴 MSN / Yahoo 这类聚合镜像（会失效或改址）
2. **热榜只当线索**：微博/知乎/抖音热榜是领先信号，不是事实源，事实必须回到一手来源核

## 合规提示（若用于新闻）

在中国大陆做"新闻转载聚合"受《互联网新闻信息服务管理规定》约束：转载只能转载国家规定范围内单位发布的内容，须注明来源、原作者、原标题。本技能只记录你自己采集/撰写的摘要与来源链接，**不转载正文**。

其他内容类型（政策、竞品、价格）按各自行业的合规与数据使用要求处理。
